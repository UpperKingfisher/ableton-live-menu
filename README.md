## 🎼 Session & Arrangement Planner

Keep your production ideas organized from the initial sketch to the final arrangement.

- Create project summaries and session notes.
- Plan intro, verse, chorus, breakdown, and outro sections.
- Document track groups and instrument roles.
- Record automation ideas and transitions.
- Maintain alternative arrangement versions.
- Track unfinished sections and revision priorities.

### Suggested Arrangement Checklist

- [ ] Define the musical idea and target style.
- [ ] Build the core rhythm and groove.
- [ ] Develop the main melodic or harmonic idea.
- [ ] Arrange sections and transitions.
- [ ] Review dynamics and track balance.
- [ ] Prepare the final mix and export.

Document the processing choices that shape your sound.

- Record EQ, compression, reverb, and delay settings.
- Document creative distortion and modulation chains.
- Organize parallel processing ideas.
- Track sidechain and routing notes.
- Compare alternative processing approaches.
- Save sound-design recipes for future sessions.

Actual plugin availability depends on your Ableton Live edition, installed devices, third-party plugins, and operating system.

## 🎚️ Mixing & Mastering Checklist

Use a repeatable process when preparing a track for release.

- [ ] Check track levels and clipping.
- [ ] Review low-frequency balance.
- [ ] Check stereo width and mono compatibility.
- [ ] Listen for unwanted noise and harsh frequencies.
- [ ] Compare the mix against suitable references.
- [ ] Review transitions and automation.
- [ ] Export a test file and listen back.
- [ ] Confirm the final file format and destination.

This checklist is a planning aid, not a substitute for listening tests or professional mastering.

## 📁 Project & File Management

Keep music sessions easy to find, reopen, and archive.

- Use consistent project names.
- Separate active projects from completed releases.
- Record the software and plugin versions used.
- Keep project notes alongside relevant files.
- Back up important sessions before major changes.
- Collect required media when archiving projects.
- Document external sample and plugin dependencies.

## 📊 Production Analytics

Track your creative progress over time.

- Record the number of active and completed tracks.
- Maintain a log of session time and milestones.
- Track revisions and outstanding tasks.
- Compare production goals with completed work.
- Record lessons learned after each release.
- Identify workflow bottlenecks and recurring problems.

Any analytics depend on information you enter or data you are authorized to access. Automatic collection from Ableton Live is not claimed.
